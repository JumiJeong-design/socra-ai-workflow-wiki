기준 문서를 먼저 다 써 둘 필요는 없습니다. 자리 셋과 결정 하나만 있으면 첫 작업을 시작할 수 있습니다. 안은 에이전트와 같이 일하면서 채웁니다.

1. 진입 파일 만들기
레포 루트에 에이전트가 세션마다 읽는 파일(AGENTS.md 또는 CLAUDE.md)을 둡니다. 이 파일이 없으면 대화가 끝날 때 규칙도 같이 사라집니다.
2분
2. 정본 순서 한 줄 적기
피그마, 코드, 스토리북 중 어느 쪽이 기준이고 어느 쪽이 따라가는지 진입 파일에 적습니다. 정하지 않으면 에이전트가 매번 다르게 판단합니다.
3분
3. 워크로그 자리 만들기
날짜별 파일 하나를 둘 폴더를 정하고, 진입 파일에 「시작할 때 오늘 것을 읽고 끝날 때 적는다」를 적습니다. 세션 사이를 이어 주는 장치입니다.
5분
4. 화면 하나 맡겨 보기
진입 파일이 읽히는지 확인하고 작업 하나를 맡깁니다. 틀린 것은 규칙으로 적되, 규칙이 늘어나면 통째로 읽히지 않으니 색인과 훅으로 옮깁니다.
