# 사례: 스토리북이 그림판이 되면 검수 표면이 아니다

> 구분: 사례 · 기간: 2026-06 ~ 09-22 · 관련: [매뉴얼 11장 채널과 게시 게이트](../manual/11-five-channels-publish-gate.md), [33장 중간안](../manual/33-principle-middle-ground.md)

AI에게 스토리북에 화면을 조합하게 했는데, 그 화면이 실제 패키지 컴포넌트와 연결돼 있는지 확신이 없는 경우의 사례다. 에이전트가 화면 스토리를 만들면서 패키지 컴포넌트를 import하지 않고 손으로 비슷한 마크업을 그리거나 자리표시 상자를 넣었다. 겉보기엔 화면이 나오는데, 패키지를 고쳐도 그 화면은 안 바뀌고 제품과 같다는 보장도 없었다.

## 한눈에

| 날짜 | 무슨 일 | 뒤집힌 것 | 그래서 |
|---|---|---|---|
| 6~8월 | 에이전트가 화면 스토리를 손 마크업과 자리표시로 그렸다 | 왜 안 쓰나를 보니 이유가 셋이었다 | 규칙 둘: 「자리표시 넣지 말고 피그마 에셋을 쓴다」 「페이지 스토리는 실제 컴포넌트로」 |
| 8/26 | 스토리북에 과한 게 많아 보였다 | 눈대중으로 지우려던 두 묶음이 계약이 요구하는 것이었다 | 계약과 대조해 진짜 중복 10개만 지웠다 |
| 8/31 | 하드코딩돼 달라 보이는 곳을 찾았다 | 규칙 뒤에도 그림판 두 곳이 남아 있었고, 그 위에서 패키지 어긋남 셋이 보였다 | 패키지 쪽도 고쳤다 |
| 9/2 | 설정 화면 로고가 혼자 컸다 | 자리표시가 피그마 컴포넌트 기본값에서도 났다. 43곳 | 스토리북만의 문제가 아니다 |
| 9/16~22 | 라이트·다크 리뷰 없는 스토리를 셈 | 35가 아니라 40이었다. 앞 문장 숫자만 받아 더했다 | 50개에 병치를 넣어 닫았다 |

에이전트가 패키지 컴포넌트를 안 쓴 이유는 셋이었다. 공개 속성이 원하는 배치와 안 맞으면 감싸는 대신 새로 그린다. 에셋을 가져오는 경로가 없으면 회색 상자를 넣는다. 「느낌만 보자」는 요청을 받으면 완성본을 빨리 내려고 지름길을 탄다.

## 원인과 처방

| 원인 | 처방 |
|---|---|
| 에이전트는 화면이 「나오게」 하는 데 최적화돼 있다 | 「자리표시 넣지 말고 피그마 에셋」 「페이지 스토리는 실제 컴포넌트로」를 프로젝트 규칙으로 |
| 패키지에 없는 컴포넌트가 필요하면 스토리북에 먼저 만든다 | 정본 순서 피그마 > 패키지 > 스토리북. 없으면 「피그마에 없다」로 보고하고 멈춘다 |
| 탐색 단계에 확정 단계의 목록을 들이댄다 | 탐색은 대표 컷 한 장, 배치 축 서너 개만 |
| 규칙은 새 세션에는 걸리지만 이미 만든 것은 안 고친다 | 감사 두 번. 「있어야 하는 스토리인가」는 계약과, 「내용이 실물과 맞나」는 패키지와 대조 |
| 자리표시는 스토리북만의 문제가 아니다 | 제품 파일에서 마스터 기본값 그대로 노출된 자리를 센다 |
| 앞 문장의 숫자를 받아 더한다 | 일괄 처리를 열 때는 그날 다시 세고 시작한다 |

## 직접 해 보려면

```text
[화면 이름] 페이지 스토리를 만들어 줘. 조건 둘.
1. 패키지 컴포넌트만 import해서 조합해. 손으로 마크업을 그리거나 자리표시 상자를 넣지 마.
2. 패키지에 없는 컴포넌트가 필요하면 만들지 말고 「피그마에 없다」로 보고하고 멈춰.
다 만들면 이 스토리가 import한 패키지 컴포넌트 목록을 보여 줘.
```

```text
지금은 탐색 단계야. 상태 전수를 만들지 말고 대표 컷 한 장과 배치 축 [개수, 예: 셋]만 만들어.
상태 목록은 방향이 확정된 뒤에 시킬 거야.
```

```text
[스토리 파일 경로]가 import하는 패키지 컴포넌트 목록을 보여 줘. 목록이 비어 있거나 패키지 밖 컴포넌트가 있으면 그 스토리는 그림판이야.
그런 스토리를 [스토리 폴더] 전체에서 세서 파일·이유 두 칸 표로.
```

```text
[스토리 폴더]의 스토리와 [계약 문서 폴더]의 요구를 전수로 대조해 줘.
계약이 요구하는데 없는 것, 계약에 없는데 있는 것, 이름만 다른 같은 것을 세 표로 나눠. 눈대중으로 지우지 말고 소비처를 세서 판정해.
지우기 전에 목록을 보여 주고 내 승인을 받아.
```

```text
[제품 파일 페이지]에서 [컴포넌트 세트 이름]의 인스턴스 중 아이콘·이미지 슬롯이 마스터 기본값 그대로인 것을 세 줘.
같은 화면의 다른 플랫폼(예: 모바일)에 제대로 된 값이 있으면 그걸 정답으로 대조해서 자리·기본값·정답 세 칸 표로.
```
